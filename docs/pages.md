# サイトの構成

記事は**ソースの `type` で3つに分ける**。作り手が書いたもの・みんなが読んでいるもの・論文は
性質も流量も違うため、同じ一覧に混ぜない。分類は `packages/site/src/lib/load-articles.ts` の
`CATEGORIES` に定義してある。

| カテゴリ | ソース種別 | ページ | 記事数 |
|---|---|---|---:|
| tech | `company_blog` / `personal_blog` / `tweet` | `/`（新着） | 2041 |
| social | `aggregator` | `/social/` | 723 |
| papers | `paper` | `/papers/` | 289 |

## なぜ分けたか

分ける前は、直近90日の記事1419件のうち**アグリゲータが708件（50%）**を占めていた。
HN とはてブは毎日十数件流れるのに対し、企業ブログは数日に1本なので、
新着順に並べるとトップがアグリゲータで埋まる。

2026-08-16 の実測: **トップ100件の内訳は aggregator 96 / personal_blog 4**（トップ20件は全部 aggregator）。
実際に並んでいたのはクレジットカード債務・嗅覚の研究・血糖記録アプリなどで、
企業ブログはトップページから消えていた。

## 分類をまたぐページ

以下は分類で切らない。

| ページ | 内容 |
|---|---|
| `/hot/` | 直近7日で HN・はてブの反応が多い記事。**スコア軸なので分類とは直交する**（企業ブログの記事も入る） |
| `/archive/[page]/` | 全記事 |
| `/tags/[slug]/[page]/` | タグ別 |
| `/sources/[id]/[page]/` | ソース別 |
| `/search/` | 全文検索（`docs/search.md`） |

## フィルタバー

`FilterBar`（Preact island）は3つの一覧ページすべてに載る。`types` prop でそのページの
ソース種別を受け取り、`recent.json`（直近90日）をその範囲に絞ってから言語・タグ・has_code で
フィルタする。**種別セレクトはそのページに2種類以上あるときだけ出す**ので、
`/social/` と `/papers/` では自動的に消える。

## RSS

`/feed.xml` は**トップページと同じ範囲（tech）の新着50件**。
Social と論文は量も性質も違うため混ぜていない。
必要になったらカテゴリごとのフィードを足せる（同じエンドポイントの書き方で増やせる）。
